# 量化分析方法教學

這份教學對應研究室裡的每個分頁，說明**每個方法在做什麼、什麼時候可以參考、什麼情況下容易騙到自己（過擬合）**。

> 先講結論：日線股價有大量雜訊，**任何方法在回測裡看起來很好都很容易，在未來繼續好很難**。這個工具的升級重點不是「預測更準」，而是「更誠實地告訴你，預測到底有沒有用」。

## 1. 這次升級改了什麼？為什麼更精確？

| 舊版問題 | 影響 | 新版做法 |
|---|---|---|
| 只抓 1 年資料，模型測試集約 60 天 | 60 天的準確率誤差約 ±13%，幾乎無法判斷好壞 | 預設抓 **5 年**，walk-forward 樣本外約 2～3 年 |
| 單次 70/30 切分 | 結果只反映「那一段」行情，換個切點可能完全不同 | **Walk-forward**：每季用過去資料重新訓練，滾動測試 |
| 預測「明天」漲跌 | 單日報酬幾乎是隨機的，訊號雜訊比極低 | 預設預測 **5 日後**漲跌，可調整 |
| 訓練與測試緊貼 | 多日標籤會跨進測試期，造成**標籤洩漏** | 中間保留 `horizon` 天空窗（purging） |
| 機率 > 50% 就進場 | 股票長期偏漲，模型只要一直說「漲」就有 55% 準確率 | 門檻改為「訓練期上漲比例」，模型必須贏過「永遠看多」 |
| 機率在 50% 附近來回就頻繁進出 | 交易成本吃掉所有報酬 | 進出場加上 ±2% 緩衝帶（hysteresis） |
| 成本只有手續費＋滑價 | 台股漏算 **0.3% 證交稅**，每次來回少算一半以上的成本 | 依市場自動帶入：台股 0.1425%×2 + 稅 0.3%（ETF 0.1%）；美股零佣金 |
| 只看準確率 | 準確率高不代表賺錢，也不代表不是運氣 | 加入 **AUC、p-value、PSR、Deflated Sharpe、訓練/測試落差** |
| 4 個特徵 | 資訊量有限 | 15 個特徵：多週期動能、RSI、MACD、布林、ATR、量能、相對大盤強弱、大盤趨勢 |
| 均線參數只看一組 | 不知道是參數好還是運氣好 | **參數穩健度**分頁：30 組參數熱力圖＋樣本內外檢驗 |
| 等權重組合 | 高波動股主導整體風險 | 新增**風險平價**（波動倒數）權重與風險貢獻 |
| 固定 5% 停損 | 對低波動股太寬、高波動股太窄 | 改用 **ATR 停損**，隨個股波動調整 |
| 只有台股 | — | 支援**美股**（AAPL、NVDA、SPY…），台股可直接輸入 `2330`，上櫃自動改用 `.TWO` |

## 2. 績效指標怎麼看

| 指標 | 意義 | 參考標準 | 陷阱 |
|---|---|---|---|
| 總報酬 / CAGR | 賺多少；CAGR 是換算成每年 | 一定要跟**同期買入持有**比 | 牛市裡什麼策略都賺錢 |
| 年化波動 | 報酬上下震盪幅度 | 大盤約 15～20% | 低波動不等於低風險（可能是流動性差） |
| **Sharpe** | 每單位波動換到的報酬 | > 0.5 普通、> 1 優秀、> 2 先懷疑有 bug | 短期間的 Sharpe 誤差極大 |
| Sortino | 只把「下跌波動」當風險 | 比 Sharpe 高很多 = 上漲波動大 | — |
| **最大回撤** | 從高點跌到低點最深的一次 | 問自己：跌這麼多我撐得住嗎？ | 歷史最大回撤 ≠ 未來最大回撤，未來通常更糟 |
| Calmar | CAGR ÷ 最大回撤 | > 0.5 不錯 | — |
| **PSR** | 「真實 Sharpe > 0」的機率，考慮樣本長度、偏態、肥尾 | ≥ 95% 才算有說服力 | 只對一組策略有效；試了很多組要看 Deflated Sharpe |
| Beta | 跟大盤連動程度 | 1 = 跟大盤一樣 | 高 Beta 的報酬多半只是大盤給的 |
| **Alpha** | 扣掉大盤貢獻後，策略自己多賺的部分 | > 0 且穩定才有意義 | — |
| 持倉比例 | 有多少天在場內 | 50% 持倉、報酬卻只有持有的一半，代表沒有擇時能力 | — |
| 勝率 / 獲利因子 | 持倉日賺錢比例 / 總獲利÷總虧損 | 趨勢策略勝率常 < 50% 但獲利因子 > 1.3 | 勝率高但虧一次很大的策略最危險 |

### Sharpe 有多不準？
Sharpe 的標準誤差大約是 `√(1/年數)`。

- 1 年資料：Sharpe 1.0 的 95% 信賴區間約 **-1.0 ～ 3.0**（等於沒結論）
- 5 年資料：約 **0.1 ～ 1.9**
- 20 年資料：約 0.55 ～ 1.45

這就是為什麼新版預設抓 5 年，也是 PSR 存在的原因。

## 3. 均線交叉策略

**做法**：短均線在長均線之上就持有，否則空手。訊號在收盤決定，**隔天**才計入報酬（避免偷看未來）。

**適用時機**
- 有明顯長期趨勢、波動大的標的（例如大盤 ETF 在空頭年份的避險）。
- 目的是**降低回撤**而非提高報酬：好的均線策略通常報酬略低於持有，但最大回撤明顯較小。

**不適用 / 容易失效**
- **盤整盤**：均線來回交叉，每次都被雙巴，加上台股來回約 0.6% 成本，損失會累積得很快。
- 單一個股的短週期（例如 5/20）：雜訊太多。
- 強勢多頭：空手的日子都是錯過的漲幅。

**判讀**：Sharpe 比持有高、最大回撤明顯較小、交易次數一年少於約 6 次 → 值得進一步研究。

## 4. 參數穩健度（最重要的防過擬合工具）

### 什麼是過擬合？
你測試 30 組參數，挑出最好的那組。就算每組其實都沒用，**最好的那組看起來也一定很好**——因為你是在「挑運氣最好的」。

新版會做三件事：

1. **熱力圖**：30 組參數各自的 Sharpe。
   - ✅ 好的跡象：一整片相近顏色的「高原」，鄰近參數表現接近。
   - ❌ 壞的跡象：只有一格特別好，周圍都很差（「尖峰」）——那是雜訊。
2. **樣本內 → 樣本外**：用前 60% 資料挑最佳參數，看它在後 40% 表現。
   - 樣本外 Sharpe 掉超過 0.5，或樣本內外排名相關性 < 0.2 → 參數選擇無效。
3. **Deflated Sharpe**：把「我試了 N 組」的運氣扣掉後，Sharpe 仍 > 0 的機率。
   - < 50%：你的結果很可能只是試出來的。
   - \> 95%：即使考慮多重測試仍然顯著。

> 實驗：用**完全隨機**的股價跑本工具的模型，6 次中有 1 次樣本外 Sharpe 達 1.65。只看一次回測結果是會被騙的。

### 你自己最容易犯的過擬合
這些都是「Deflated Sharpe 看不到」的隱形試驗次數，要自己記住：
- 改了 10 次參數，只記得最後那個好看的。
- 換了好幾支股票，只留下回測漂亮的那支。
- 看到某段行情虧錢，就加一條規則把它排除掉。
- 看了樣本外結果之後再回頭調參數——樣本外就不再是樣本外了。

**對策**：先寫下規則與參數，再看結果；同一套規則拿去跑 5～10 支不同股票（台股＋美股），大多數都有效才可信。

## 5. 機器學習（Walk-forward）

### 流程
```
|-------- 訓練（過去所有資料）--------|空窗 h 天|-- 測試 63 天 --|
|------------- 訓練（再多 63 天）-------------|空窗|-- 測試 63 天 --|
...一路滾動到今天
```
每一個預測都來自**當時還沒看過那段行情**的模型，這最接近「如果當時真的用這個模型」的結果。

### 標的與特徵
- **標籤**：`horizon` 天後的收盤價是否高於今天。
- **特徵**：多週期報酬（1/5/20/60 日）、RSI、MACD 柱、布林 %B、ATR%、波動率與波動比、成交量 Z 分數、距 120 日高點、均線比、相對大盤強弱、大盤是否在 200 日均線上。全部只用「當天以前」的資料。

### 三個模型
| 模型 | 特性 | 適合 | 過擬合風險 |
|---|---|---|---|
| Logistic Regression | 線性、參數少、可解釋 | **預設首選**，資料少時最穩 | 低 |
| Random Forest | 多棵淺樹投票 | 特徵之間有交互作用時 | 中（已限制深度 4、葉節點 ≥ 40） |
| HistGradientBoosting | 逐步修正錯誤 | 資料量大（10 年以上、多股票） | **高** |

### 怎麼判斷模型有沒有用？依序檢查：
1. **AUC > 0.53**：AUC 不受門檻影響，0.5 = 丟銅板。日線股票能穩定做到 0.55 已經很好。
2. **準確率 > 基準準確率**：基準 = 永遠猜比較常發生的那一邊。
3. **p-value < 0.05**：準確率勝過基準的部分不像運氣。（因為 5 日標籤彼此重疊，計算時樣本數已除以 horizon，比較保守。）
4. **訓練準確率 − 樣本外準確率 < 10%**：差距太大就是在「背答案」。
5. **扣成本後的 Sharpe > 同期買入持有**，且 PSR > 90%。

**五項都過才值得參考「最新讀數」**。大部分股票、大部分時候都過不了——這是正常的，代表市場對這些公開技術指標已相當有效率。

### 容易過擬合的情況
- 資料少於 3 年，或樣本外少於 1 年。
- 用 Gradient Boosting / 深的樹，卻只有一支股票、幾百筆資料。
- 一直加特徵（特徵數接近樣本數 / 50 就要小心）。
- 在不同 horizon、模型、門檻間來回切換，挑最好看的組合（也是多重測試）。
- 期間剛好只有一種行情（例如 2023–2024 AI 多頭），模型只學到「一直漲」。

### 適當的參考時機
- ✅ 作為**輔助濾網**：例如均線策略要進場時，模型也偏多才進場。
- ✅ 比較不同股票的「可預測性」：AUC 長期高於 0.55 的標的值得深入研究。
- ❌ 不要當成每天的買賣訊號直接下單。
- ❌ 財報、除權息、重大消息前後，技術面特徵的資訊量會大幅下降。

## 6. 投資組合與風險

### 等權重 vs 風險平價
- **等權重**：每檔一樣多錢。簡單，但 NVDA（波動 50%）和 0050（波動 18%）放在一起時，組合的風險幾乎都來自 NVDA。
- **風險平價（波動倒數）**：低波動的多買、高波動的少買，讓每檔貢獻的風險較接近。通常降低回撤，但在強勢單一飆股行情中報酬會落後。
- 波動是用**再平衡日之前** 60 天計算，沒有偷看未來。

### 相關係數
- 台股電子股彼此相關常 > 0.6，分散效果有限；加入美股或債券 ETF 分散效果較好。
- 危機時相關性會一起升高，平常的分散效果在崩盤時會打折。

### ATR 停損與部位大小
- `建議股數 = 資金 × 單筆風險% ÷ (股價 × 停損距離)`
- 停損距離 = `ATR 倍數 × ATR(14) ÷ 股價`；常用 2～3 倍。
- 單筆風險 1%：連錯 10 次約虧 10%；超過 2% 就要非常有把握。
- 台股一張 = 1000 股，工具會換算張數與零股。

## 7. 台股 vs 美股注意事項

| | 台股 | 美股 |
|---|---|---|
| 代號 | `2330`、`2330.TW`；上櫃 `6488.TWO` | `AAPL`、`BRK.B`（自動轉 `BRK-B`） |
| 手續費 | 0.1425%（買賣各一次，可依券商折扣自行輸入） | 多數券商 0 |
| 交易稅 | 賣出 0.3%（ETF 0.1%、當沖減半） | 幾乎沒有（極小的 SEC 費用） |
| 來回成本（含滑價） | 約 0.69% | 約 0.10% |
| 基準 | 0050.TW | SPY |
| 漲跌停 | ±10%，停損單可能無法成交 | 無漲跌停，但有盤前盤後跳空 |
| 資料 | Yahoo 調整後價格（已含除權息），台股高配息所以很重要 | 同左 |

**同一個策略在美股可能賺錢、在台股卻虧錢**，差別常常只在成本。短線策略在台股特別吃虧。

## 8. 大盤總覽（偏多 / 偏空名單）

`/market` 一次掃描台股約 40 檔、美股約 35 檔大型股，回答兩個問題：**現在市場整體是什麼狀態？哪些股票趨勢最強、哪些最弱？**

### 市場狀態怎麼判斷
| 狀態 | 條件 | 意思 |
|---|---|---|
| 多頭 | 指數在 200 日線之上，且 ≥ 55% 個股站上 200 日線 | 大部分股票一起漲，趨勢訊號最可靠 |
| 空頭 | 指數在 200 日線之下，且 ≤ 45% 個股站上 200 日線 | 大部分股票走弱，「偏多」名單也容易失靈 |
| 震盪 / 轉折 | 其他情況 | 常見於指數靠少數權值股撐住（例如台積電），但多數股票其實在跌 |

**市場廣度**（站上 200 日線的比例）是最被低估的指標：指數創新高、但廣度一路下滑，代表上漲越來越集中在少數股票，歷史上常是行情後段的跡象。

### 分類規則
- **偏多**：站上 200 日線＋ 50 日線在 200 日線之上＋綜合分數 ≥ 65＋沒有過熱。
- **過熱**：趨勢向上，但 RSI ≥ 75 或高於 50 日線 15% 以上。不是賣出訊號，而是「追高風險報酬差」。
- **偏空**：跌破 200 日線＋ 50 日線在 200 日線之下＋綜合分數 ≤ 35。
- **中性**：其他。

為什麼不用機器學習？前面的 walk-forward 測試顯示，模型在多數個股上沒有穩定的預測力，而且很慢。**趨勢**和**橫斷面動能**（強的股票傾向繼續強一段時間）是研究歷史最長、跨市場都觀察得到的現象，規則也簡單到你可以自己驗證。

### 怎麼用比較合理
- ✅ 當作**候選名單**：偏多名單裡挑你看得懂的公司，再用個股研究室看細節與風險。
- ✅ 當作**持股健檢**：手上的股票出現在偏空名單，就該問自己當初買進的理由還在不在。
- ✅ 先看**市場狀態**再看名單：空頭時偏多名單的勝率明顯下降。
- ❌ 不要每天照名單進出：動能是以「月」為單位的效應，天天換股只會被成本吃掉（台股來回約 0.69%）。
- ❌ 不要因為「偏空」就放空：大型股跌深常有劇烈反彈。

### 頁面上的回測在測什麼
每月買進偏多名單分數最高的 10 檔（不足就放現金），和「名單內全部等權重」比較。

**這個回測一定偏樂觀**，因為名單是今天的大型股，等於事先知道誰會長大（倖存者偏差）。所以要看的是「規則**相對**等權重有沒有優勢」，而不是絕對報酬。動能策略已知的弱點是**急跌後的 V 型反彈**（例如 2020 年 4 月、2022 年底），這時過去最弱的股票反彈最猛，規則會明顯落後。

### 什麼時候容易過擬合
- 看到回測不好，就改權重（35%/25%/25%/15%）或門檻（65/35）直到變好——這就是在擬合過去。
- 只挑回測好看的市場或期間來相信。
- 自己修改名單時，只放「最近表現好」的股票。

## 9. 這個工具「做不到」的事

- **存活者偏差**：你只會輸入現在還存在的股票，下市的看不到，回測會偏樂觀。
- **成交假設**：假設以收盤價成交，實際上可能有跳空、漲跌停、流動性不足。
- **資料品質**：Yahoo Finance 偶有缺漏或錯誤，Render 免費方案重啟會清空 SQLite 快取。
- **基本面與消息**：模型只看價量，看不到財報、法說會、總經事件。
- **未來的市場結構**：再好的回測都只描述過去。

> 建議流程：先看大盤總覽 → 參數穩健度通過 → 換 5～10 支股票驗證 → 小資金或模擬交易至少 3～6 個月 → 才考慮放大。
